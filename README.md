# ใบสั่งงานฝึกงาน

เว็บสำหรับสั่งงาน รับทราบ ส่งงาน และตรวจงาน ของนักศึกษาฝึกงาน (สหกิจศึกษา) กับพนักงานผู้ดูแล
ใช้บนมือถือเป็นหลัก ฟรีทั้งหมด (Firebase แพ็กเกจ Spark + GitHub Pages)

## ทำอะไรได้

| ใคร | ทำอะไร |
|---|---|
| พนักงานผู้ดูแล | สั่งงาน (ผู้มอบหมาย กำหนดส่ง ความสำคัญ ลำดับ งานกลุ่ม/แยกรายคน) · ตรวจผ่านหรือให้แก้ · ลงแผน 16 สัปดาห์ |
| นักศึกษา | กดรับทราบ · ส่งงานพร้อมรูปหรือลิงก์ · ดูงานที่ต้องทำเรียงตามกำหนดส่ง |
| แอดมิน | อนุมัติคนเข้าระบบ · ตั้งบทบาท · ตั้งช่วงฝึกงาน · สำรองข้อมูล |
| ทุกคน | ฟอร์มส่งมหาลัย (แบบแจ้งแผนปฏิบัติงานสหกิจศึกษา) ดึงจากแผนอัตโนมัติ พิมพ์หรือบันทึก PDF ได้ |

เรียงงาน: ถ้าใส่ "ลำดับ" จะเรียงตามลำดับก่อน ที่เหลือเรียงตามกำหนดส่ง แล้วตามความสำคัญ

## ติดตั้งครั้งแรก (ทำผ่านเว็บเบราว์เซอร์ทั้งหมด)

1. **Firebase** (console.firebase.google.com)
   - Authentication → Sign-in method → เปิด **Google**
   - Firestore Database → Create database (Standard, production mode)
   - Project Overview → Add app → Web → คัดลอก `firebaseConfig` มาใส่ในไฟล์ `js/config.js`
2. **กฎสิทธิ์** — Firestore Database → แท็บ **Rules** → ลบของเดิม วางเนื้อหาไฟล์ `firestore.rules` ทั้งไฟล์ → **Publish**
3. **GitHub Pages** — repo นี้ → Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
   เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/coop-tasks/`
4. **อนุญาตโดเมน** — Firebase → Authentication → Settings → Authorized domains → Add domain → `<ชื่อผู้ใช้>.github.io`
5. **ตั้งแอดมิน** — เปิดเว็บ ล็อกอินด้วย Google แล้วกด **ตั้งฉันเป็นแอดมิน** (ทำทันทีหลังเปิดเว็บครั้งแรก คนแรกที่กดจะเป็นแอดมิน)
   จากนั้นเข้า **จัดการระบบ** กรอกชื่อสถานประกอบการ
6. **ชวนคนเข้า** — ส่งลิงก์ให้พี่ผู้ดูแลและเพื่อนนักศึกษา ให้ล็อกอินด้วย Google แล้วแอดมินกดอนุมัติในหน้า **จัดการระบบ**
   แต่ละคนกดชื่อตัวเองมุมขวาบนเพื่อกรอก **ข้อมูลของฉัน** (เลขประจำตัว สาขา คณะ / ตำแหน่ง) ใช้ลงฟอร์มมหาลัย

## ข้อควรรู้

- **ไม่มีค่าใช้จ่าย** ไม่ต้องเปิด Cloud Storage และไม่ต้องอัปเกรดเป็น Blaze
  รูปถ่ายถูกย่อในมือถือ (ไม่เกิน ~900 KB ต่อรูป) แล้วเก็บใน Firestore · ไฟล์ใหญ่อย่าง PDF ให้แปะลิงก์ Google Drive
- **เปิดลิงก์จาก LINE** จะล็อกอิน Google ไม่ได้ ในหน้าล็อกอินมีปุ่มให้เปิดใน Chrome หรือ Safari
- **เน็ตหลุด** กดงานไว้ได้ ระบบส่งให้อัตโนมัติเมื่อกลับมาออนไลน์
- **โหมดตัวอย่าง** เติม `?demo` ท้ายลิงก์ จะเห็นข้อมูลสมมติ ไม่แตะข้อมูลจริง
- **ใช้เหมือนแอป** มือถือ Android: Chrome → เมนู ⋮ → เพิ่มลงในหน้าจอหลัก · iPhone: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- "เดือนที่" ในฟอร์มมหาลัยคือช่วงละ 4 สัปดาห์ นับจากวันเริ่มฝึกงาน (ตั้งได้ในจัดการระบบ)

## โครงสร้างโค้ด

ไม่มีขั้นตอน build — เป็น HTML/CSS/JavaScript (ES modules) ใช้ Preact + htm (ไฟล์ใน `js/vendor/`)

```
index.html              หน้าเว็บ
css/app.css             หน้าตาทั้งหมด
js/main.js              เริ่มระบบ: มี config → Firebase, ไม่มี → โหมดตัวอย่าง
js/config.js            firebaseConfig
js/model.js             วันที่ไทย ปฏิทิน 16 สัปดาห์ สถานะงาน การเรียงงาน
js/store-firebase.js    อ่าน/เขียน Firestore + ล็อกอิน Google
js/store-demo.js        ข้อมูลตัวอย่าง (ในเครื่อง)
js/views/*.js           หน้าต่างๆ: งานของฉัน ภาพรวม งานทั้งหมด ใบสั่งงาน แผน ฟอร์มมหาลัย จัดการระบบ
firestore.rules         กฎสิทธิ์ (pending / student / supervisor / admin)
```

โครงข้อมูลใน Firestore: `users`, `tasks` (+ `progress/{uid}` สถานะรายคน, `subs` การส่งงานแต่ละครั้ง), `plans`, `attachments` (รูป), `activity`, `settings/app`, `meta`

## แผนต่อไป: สรุปงานค้างทุกเช้า (ร่าง)

ทำตอนย้ายโปรเจกต์ไปเปิดด้วย Claude Code บนเครื่องตัวเอง

1. สร้าง service account ใน Firebase (Project settings → Service accounts) เก็บไฟล์ key ไว้ในเครื่อง **ห้าม** ใส่ใน repo
2. ตั้ง scheduled task ทุกเช้า (เช่น 07:30 จันทร์–เสาร์) ให้อ่านงานที่เลยกำหนด ครบกำหนดวันนี้ และรอตรวจ
3. เขียนสรุปลง collection `digests` แล้วให้หน้า "ภาพรวม" แสดงกล่อง "สรุปเช้านี้"
