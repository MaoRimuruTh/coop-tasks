# ใบสั่งงานฝึกงาน

เว็บสำหรับสั่งงาน รับทราบ ส่งงาน และตรวจงาน ของนักศึกษาฝึกงาน (สหกิจศึกษา) กับพนักงานผู้ดูแล
ใช้บนมือถือเป็นหลัก ฟรีทั้งหมด (Firebase แพ็กเกจ Spark + GitHub Pages)

## ทำอะไรได้

| ใคร | ทำอะไร |
|---|---|
| พนักงานผู้ดูแล | สั่งงาน (ผู้มอบหมาย กำหนดส่ง ความสำคัญ ลำดับ งานกลุ่ม/แยกรายคน) · ลบใบสั่งงานที่สั่งผิด · ตรวจผ่านหรือให้แก้ · ลงแผน 16 สัปดาห์ พร้อมหัวข้อย่อย · รับดูแลน้อง (เป็นพนักงานที่ปรึกษา) · รับรองบันทึกงานที่น้องลงเอง |
| นักศึกษา | กดรับทราบ · ส่งงานพร้อมรูปหรือลิงก์ · ดูงานที่ต้องทำเรียงตามกำหนดส่ง · เลือกพี่ที่ดูแลเรา · ลงบันทึกงานที่ทำจริงแต่ไม่ได้มาเป็นใบสั่งงาน |
| พี่กับน้อง | แชทแบบแอปแชททั่วไป: คุยทีละคน (พี่ ↔ น้อง) หรือสร้างกลุ่มเลือกคนเองได้ (ต้องมีพี่อย่างน้อย 1 คน) ในเว็บเห็นเฉพาะคนในแชท |
| แอดมิน | ส่งลิงก์ชวนเข้าทีม · ตั้งบทบาท · ข้อมูลสถานประกอบการ · ช่วงและเวลาฝึกงาน · สำรองข้อมูล |
| ทุกคน | ฟอร์มส่งมหาลัย (แบบแจ้งแผนปฏิบัติงานสหกิจศึกษา) ดึงจากแผนอัตโนมัติ · หน้ารายเดือน 4 หน้า (ตารางติก + บันทึกรายวัน) · พิมพ์หรือบันทึก PDF ได้ |

เรียงงาน: ถ้าใส่ "ลำดับ" จะเรียงตามลำดับก่อน ที่เหลือเรียงตามกำหนดส่ง แล้วตามความสำคัญ
เวลาส่งงานตั้งต้น = เวลาเลิกฝึกงานที่ตั้งไว้ในจัดการระบบ (เวลาทำการของบริษัทเก็บแยกไว้อีกช่อง)

### แผน หัวข้อย่อย และหน้ารายเดือน

- หัวข้องาน (หัวใหญ่) มีหัวข้อย่อยได้ พิมพ์ชื่อแล้วแตะจำนวนสัปดาห์ ระบบวางต่อจากข้อก่อนหน้า ปรับด้วย ◀ ▶ และ − +
- หัวใหญ่ติกตามหัวข้อย่อยอัตโนมัติ (ตั้งแต่ข้อแรกถึงข้อสุดท้าย) ถ้าเลือกสัปดาห์ของหัวใหญ่ไว้ก่อน ระบบจะคงไว้ตามที่เลือก
- ฟอร์มส่งมหาลัย: หัวใหญ่มีเลขข้อ หัวข้อย่อยอยู่ข้างใต้ไม่มีเลข (กระดาษมี 14 แถว เกินจะเตือน)
- หน้าแผนสลับ ภาพรวม / เดือน 1–4: แต่ละเดือนมีตารางติก 4 สัปดาห์ (สีเหลือง + นับสัปดาห์) และบันทึกรายวันจันทร์–เสาร์ (งานที่มอบหมาย ✓ รู้งานแล้ว ✓ ส่งงานแล้ว) พิมพ์ได้
- ใบสั่งงานเลือกได้ว่าอยู่ใต้หัวใหญ่หรือหัวข้อย่อยไหน (เลือกให้อัตโนมัติจากสัปดาห์ของวันกำหนดส่ง)
- ฟอร์มส่งมหาลัยใช้แบบฟอร์ม Coop ๐๘ ตัวจริงของมหาวิทยาลัยทักษิณเป็นพื้นหลัง (`forms/coop08.svg`) แล้ววางข้อมูลทับตามตำแหน่งช่อง ข้อความยาวจะย่อให้พอดีช่องเอง

### สั่งผิด ความเห็น พี่ผู้ดูแล และแชท

- **สั่งผิด**: หลังกดสั่งงานมีปุ่ม **ยกเลิก** บนแถบแจ้งเตือนราว 7 วินาที · หลังจากนั้นเปิดใบสั่งงาน → **ลบใบสั่งงานนี้** (แตะสองครั้ง) การลบขึ้นในประวัติการใช้งาน
- **ความเห็นในใบสั่งงาน**: ใต้ใบสั่งงานมีช่อง “ความเห็น” พี่ผู้ดูแล แอดมิน และน้องที่ได้งานนั้นคุยเรื่องงานได้ แยกจากแชท · มีเลขกับจุดแดงที่แถวงานเมื่อมีความเห็นใหม่ (เฉพาะน้องที่ได้งาน คนสั่ง และคนที่เคยแสดงความเห็น) · ลบใบสั่งงานแล้วความเห็นหายไปด้วย
- **แก้หรือยกเลิกข้อความ**: ข้อความแชทและความเห็นของตัวเองแก้หรือยกเลิกได้ภายใน 15 นาทีหลังส่ง (แตะที่ข้อความ) ข้อความที่แก้มีคำว่า “แก้ไขแล้ว” ข้อความที่ยกเลิกเหลือแค่ “ยกเลิกข้อความแล้ว” ตัวข้อความถูกลบจริง · เลย 15 นาทีแล้วแก้ไม่ได้ (บังคับในกฎสิทธิ์)
- **พี่ที่ดูแล (พนักงานที่ปรึกษา)**: น้องหนึ่งคนมีพี่ที่ดูแลได้หลายคน (สูงสุด 5) น้องเลือกเองที่ “ข้อมูลของฉัน” และเลือกว่าพี่คนไหนลงชื่อในฟอร์ม (ฟอร์มมีช่องเดียว) · พี่แตะรับดูแลหรือเลิกดูแลน้องได้เฉพาะตัวเอง ที่ “ข้อมูลของฉัน” หรือหน้าฟอร์มส่งมหาลัย (ถ้าไม่มีใครเลือกและมีพี่คนเดียวในระบบ ใช้คนนั้นให้เอง)
- **แชท**: เมนู **แชท** มีจุดแดงเมื่อมีข้อความใหม่
  - คุยทีละคนระหว่างพี่กับน้อง หรือกด **สร้างกลุ่ม** เลือกคนเข้ากลุ่มได้ (ต้องมีพี่อย่างน้อย 1 คน น้องสร้างกลุ่มจะติ๊กพี่ที่ดูแลไว้ให้ก่อน) ทักในกลุ่มทีเดียวทุกคนเห็น เหมาะกับฝากทักหรือฝากบอกต่อ
  - พี่ในกลุ่มเปลี่ยนชื่อกลุ่ม เพิ่มหรือเอาคนออกได้ (ขึ้นเป็นบรรทัดแจ้งในแชท) · ทุกคนออกจากกลุ่มเองได้ ออกแล้วอ่านกลุ่มนั้นไม่ได้อีก
  - ในเว็บไม่มีใครอ่านได้นอกจากคนในแชท แม้แต่แอดมิน (เจ้าของโปรเจกต์ Firebase ยังเปิดดูข้อมูลผ่าน Firebase console ได้ เหมือนข้อมูลอื่นทั้งหมด) · ข้อความแก้หรือยกเลิกได้ภายใน 15 นาทีเท่านั้น · ส่งได้แค่ข้อความ รูปให้ส่งผ่านการส่งงาน · ไม่มีแจ้งเตือนเด้งเข้ามือถือตอนปิดเว็บ · ถ้าเพิ่มคนเข้ากลุ่มเก่า คนนั้นจะเห็นข้อความย้อนหลังทั้งหมด

### บันทึกงานที่ทำ (งานที่ไม่ได้มาเป็นใบสั่งงาน)

- น้องลงงานที่ทำจริงแต่ไม่ได้มาเป็นใบสั่งงานเอง เช่น พี่สั่งปากเปล่า หัวหน้าเรียกไปช่วย ไปอบรม ที่เมนู **บันทึก** → ปุ่ม **บันทึกงาน**: วันที่ ช่วงเช้า/บ่าย/ทั้งวัน ทำอะไร ใครสั่ง เสร็จหรือยัง รายละเอียด หัวข้องานในแผน และหลักฐาน (รูปได้ 4 รูป ย่อในเครื่อง หรือแปะลิงก์ Drive / ชื่อไฟล์)
- ทุกรายการมีป้าย “บันทึกเอง” ไม่ใช่ใบสั่งงาน และไม่แตะสถานะของใบสั่งงาน · ลงย้อนหลังได้ แต่จะขึ้นว่า “ลงย้อนหลัง เขียนเมื่อ…” (เวลาเขียนเป็นเวลาเซิร์ฟเวอร์ แก้เองไม่ได้) · ลงล่วงหน้าไม่ได้
- ลงได้เลยโดยไม่ต้องรอใคร พี่ไม่ถูกเตือนหรือขอให้กดอะไร · พี่ผู้ดูแลเปิดดูได้ที่เมนู **บันทึก** ถ้าว่างจะกด **รับรอง** ทีละรายการหรือทั้งสัปดาห์ก็ได้ (ไม่บังคับ)
- น้องแก้รายการที่พี่รับรองแล้ว การรับรองจะหายไป · ลบได้เฉพาะรายการที่ยังไม่มีใครรับรอง · แอดมินที่เป็นนักศึกษาด้วยลงบันทึกของตัวเองได้ แต่รับรองไม่ได้ แม้แต่ของตัวเอง (ทั้งหมดบังคับในกฎสิทธิ์)
- น้องเห็นแค่บันทึกของตัวเอง พี่ผู้ดูแลและแอดมินเห็นของทุกคน · หน้ารายเดือนแสดงบันทึกเองใต้วันที่ทำ พร้อมสถานะรับรอง

### โหมดผู้มอบงาน (แอดมินที่เป็นนักศึกษาด้วย)

- ปกติบัญชีนี้สั่งงาน แก้ใบสั่งงาน และลงแผนไม่ได้ และตรวจงานใครไม่ได้เลย (บังคับใน `firestore.rules`)
- ปลดล็อกได้ครั้งละ 1 ชั่วโมงด้วยรหัสใช้ครั้งเดียวที่ชิเอลถือไว้ ในกฎเก็บแค่ค่า SHA-256 ของรหัส
- ต้องบอกเหตุผลทุกครั้ง เหตุผลขึ้นในประวัติการใช้งาน แม้ปลดล็อกแล้วก็แก้งานที่ตัวเองเป็นผู้รับไม่ได้
- แอดมินเปลี่ยนบทบาทของตัวเองไม่ได้
- รหัสหมดหรือหาย: ให้ชิเอลออกชุดใหม่ (แก้รายการ hash ใน `firestore.rules` แล้ว Publish ใหม่)

## ติดตั้งครั้งแรก (ทำผ่านเว็บเบราว์เซอร์ทั้งหมด)

1. **Firebase** (console.firebase.google.com)
   - Authentication → Sign-in method → เปิด **Google**
   - Firestore Database → Create database (Standard, production mode)
   - Project Overview → Add app → Web → คัดลอก `firebaseConfig` มาใส่ในไฟล์ `js/config.js`
2. **กฎสิทธิ์** — Firestore Database → แท็บ **Rules** → ลบของเดิม วางเนื้อหาไฟล์ `firestore.rules` ทั้งไฟล์ → **Publish**
3. **GitHub Pages** — repo นี้ → Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
   เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/coop-tasks/`
4. **อนุญาตโดเมน** — Firebase → Authentication → Settings → Authorized domains → Add domain → `<ชื่อผู้ใช้>.github.io`
5. **ตั้งแอดมิน** — เปิดเว็บ ล็อกอินด้วย Google แล้วกด **ตั้งฉันเป็นแอดมิน** (ทำทันทีหลังเปิดเว็บครั้งแรก คนแรกที่กดจะเป็นแอดมิน)
   จากนั้นเข้า **จัดการระบบ** กรอกชื่อสถานประกอบการ
6. **ชวนคนเข้า** — หน้า **จัดการระบบ** → **ลิงก์ชวนเข้าทีม** มี 2 ลิงก์: สำหรับพี่ผู้ดูแล และสำหรับนักศึกษา
   คนที่ได้ลิงก์เปิด ล็อกอินด้วย Google กรอกข้อมูลสั้นๆ (พี่ผู้ดูแล: ตำแหน่ง · นักศึกษา: เลขประจำตัวนิสิต สาขา คณะ) แล้วใช้ได้ทันที ไม่ต้องรออนุมัติ
   ลิงก์พี่ผู้ดูแลส่งให้พนักงานเท่านั้น ถ้าหลุดไปกด **เปลี่ยนลิงก์** ลิงก์เก่าจะใช้ไม่ได้ · การลงทะเบียนทุกครั้งขึ้นในประวัติการใช้งาน

## ข้อควรรู้

- **ไม่มีค่าใช้จ่าย** ไม่ต้องเปิด Cloud Storage และไม่ต้องอัปเกรดเป็น Blaze
  รูปถ่ายถูกย่อในมือถือ (ไม่เกิน ~900 KB ต่อรูป) แล้วเก็บใน Firestore · ไฟล์ใหญ่อย่าง PDF ให้แปะลิงก์ Google Drive
- **เปิดลิงก์จาก LINE** จะล็อกอิน Google ไม่ได้ ในหน้าล็อกอินมีปุ่มให้เปิดใน Chrome หรือ Safari
- **เน็ตหลุด** กดงานไว้ได้ ระบบส่งให้อัตโนมัติเมื่อกลับมาออนไลน์
- **โหมดตัวอย่าง** เติม `?demo` ท้ายลิงก์ จะเห็นข้อมูลสมมติ ไม่แตะข้อมูลจริง
- **ใช้เหมือนแอป** มือถือ Android: Chrome → เมนู ⋮ → เพิ่มลงในหน้าจอหลัก · iPhone: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- "เดือนที่" ในฟอร์มมหาลัยคือช่วงละ 4 สัปดาห์ นับจากวันเริ่มฝึกงาน (ตั้งได้ในจัดการระบบ)

## โครงสร้างโค้ด

ไม่มีขั้นตอน build — เป็น HTML/CSS/JavaScript (ES modules) ใช้ Preact + htm (ไฟล์ใน `js/vendor/`)

```
index.html              หน้าเว็บ
css/app.css             หน้าตาทั้งหมด
js/main.js              เริ่มระบบ: มี config → Firebase, ไม่มี → โหมดตัวอย่าง
js/config.js            firebaseConfig
js/model.js             วันที่ไทย ปฏิทิน 16 สัปดาห์ สถานะงาน การเรียงงาน
js/store-firebase.js    อ่าน/เขียน Firestore + ล็อกอิน Google
js/store-demo.js        ข้อมูลตัวอย่าง (ในเครื่อง)
js/views/*.js           หน้าต่างๆ: งานของฉัน ภาพรวม งานทั้งหมด ใบสั่งงาน บันทึกงานที่ทำ แชท แผน หน้ารายเดือน ฟอร์มมหาลัย จัดการระบบ
forms/coop08.svg        แบบฟอร์ม Coop ๐๘ ตัวจริง (แปลงจาก PDF ของมหาลัย) ใช้เป็นพื้นหลังฟอร์มส่งมหาลัย
firestore.rules         กฎสิทธิ์ (pending / student / supervisor / admin)
```

โครงข้อมูลใน Firestore: `users` (+ `mentors` = uid ของพี่ที่ดูแล, `mentor` = พี่ที่ลงชื่อในฟอร์ม), `tasks` (+ `progress/{uid}` สถานะรายคน, `subs` การส่งงานแต่ละครั้ง), `plans` (+ `steps` หัวข้อย่อย), `attachments` (รูป), `activity`, `settings/app`, `meta` (+ `meta/join` รหัสในลิงก์ชวน), `joins` (รหัสที่แต่ละคนใช้ลงทะเบียน), `unlocks` (รหัสปลดล็อกที่ใช้แล้ว), `chats` (แชทคู่ id `uidA_uidB` หรือกลุ่ม `kind: group` + ชื่อ + พี่หลักของกลุ่ม; สมาชิก ข้อความล่าสุด เวลาที่อ่าน) + `msgs` (ข้อความ เวลาเซิร์ฟเวอร์ `sys` = บรรทัดแจ้ง `editedAt`/`deleted` = แก้/ยกเลิก), `tasks/{id}/comments` (ความเห็น), `talk/{taskId}` (สรุปความเห็นสำหรับจุดแดง), `seen/{uid}` (อ่านความเห็นงานไหนไปแล้ว อ่านได้เฉพาะเจ้าของ), `logs` (บันทึกงานที่ทำ: `by` `day` `slot` `title` `from` `status` `detail` `proof`, `photos` = id ใน `attachments`, `at` เวลาเซิร์ฟเวอร์ที่เขียน, `okBy`/`okAt` = พี่ที่รับรอง)

## แผนต่อไป: สรุปงานค้างทุกเช้า (ร่าง)

ทำตอนย้ายโปรเจกต์ไปเปิดด้วย Claude Code บนเครื่องตัวเอง

1. สร้าง service account ใน Firebase (Project settings → Service accounts) เก็บไฟล์ key ไว้ในเครื่อง **ห้าม** ใส่ใน repo
2. ตั้ง scheduled task ทุกเช้า (เช่น 07:30 จันทร์–เสาร์) ให้อ่านงานที่เลยกำหนด ครบกำหนดวันนี้ และรอตรวจ
3. เขียนสรุปลง collection `digests` แล้วให้หน้า "ภาพรวม" แสดงกล่อง "สรุปเช้านี้"
